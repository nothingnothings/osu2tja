# osu2tja

A command-line tool that converts [osu!](https://osu.ppy.sh/) beatmaps (`.osz` files) into
[Taiko no Tatsujin](https://en.wikipedia.org/wiki/Taiko_no_Tatsujin) charts (`.tja` files),
ready to be dropped into rhythm-game simulators such as OpenTaiko.

## Highlights

- **Batch conversion** — drop any number of `.osz` files into the root of the project, run the
  script once, and *every* song is converted. No need to handle files one by one.
- **Background video support** — the converter scans each extracted beatmap for video files
  (`.mp4`, `.avi`, `.flv`, `.wmv`, `.mkv`) and writes a `BGMOVIE:` line into the generated
  `.tja`, so the song's video (e.g. the `.mp4`) plays along with the chart.
- **Tidy output** — everything is written to the `osu-tracks/` folder, one subfolder per song,
  with a single merged `.tja` containing all difficulties as separate `COURSE` sections.
- **Faithful conversion** — circles become Don/Katsu (big notes included, based on hitsounds),
  sliders become drum rolls, spinners become balloons, and BPM changes, scroll-speed changes,
  go-go time and measure changes are all preserved.
- **Difficulty detection** — each difficulty is mapped to a Taiko course
  (Easy / Normal / Hard / Oni / Edit) based on its name or note density, and a star level is
  estimated automatically.
- **osu!taiko aware** — when a beatmap contains real osu!taiko difficulties, those are preferred
  over converted standard-mode difficulties (use `--all` to convert everything anyway).
- **No dependencies** — the script runs on the Python standard library alone.

## Requirements

- Python 3.8 or newer
- osu! beatmaps packaged as `.osz` files (the format downloaded from the osu! website or
  in-game export)

## Usage

### 1. Clone the repository

```bash
git clone https://github.com/nothingnothings/osu2tja.git
cd osu2tja
```

### 2. Create a virtual environment (recommended)

The script has no third-party dependencies, but a virtual environment keeps your system
Python clean.

```bash
python -m venv .venv
```

Activate it:

**Windows (PowerShell)**

```powershell
.venv\Scripts\Activate.ps1
```

**Windows (cmd)**

```console
.venv\Scripts\activate.bat
```

**macOS / Linux**

```bash
source .venv/bin/activate
```

### 3. Add your songs

Copy or download the `.osz` files you want to convert into the **root of the project** (the
same folder as `osu2tja.py`).

```
osu2tja/
├── osu2tja.py
├── song_a.osz
├── song_b.osz
└── ...
```

### 4. Run the converter

```bash
python osu2tja.py
```

The script finds every `.osz` in the project folder, extracts each one, converts all of its
difficulties, and writes the results to `osu-tracks/`:

```
osu-tracks/
└── Song Title/
    ├── Song Title.tja   <- all difficulties merged into one file
    ├── audio.mp3
    ├── video.mp4        <- referenced by BGMOVIE, plays along with the chart
    └── ...
```

Point your favorite TJA-compatible game (e.g. OpenTaiko) at the `osu-tracks/` folder, or copy
the generated song folders into its song directory.

### Command-line options

| Option | Description |
| --- | --- |
| `-a`, `--all` | Also convert non-taiko difficulties when a beatmap already contains real osu!taiko difficulties. |
| `-g`, `--guess` | Let the converter guess unusual measure lengths instead of picking the closest standard one. |
| `-i`, `--ignore_version` | Suppress the warning for osu! file formats outside the supported range. |
| `-d`, `--debug` | Print extra per-bar debug info in the generated chart. |

Example:

```bash
python osu2tja.py --all
```

## Notes

- Supported osu! file formats are v8 through v17; newer formats trigger a warning but are
  usually still converted fine.
- Each song's difficulties are merged into a single `.tja` with one `COURSE` section per
  difficulty — the layout games like OpenTaiko expect. When two difficulties land on the same
  course, one is moved to a nearby free slot; if none is free, the extra difficulty is skipped
  with a message.
- Old `.tja` files from previous runs are removed from a song folder before writing the new
  one, so stale charts don't pile up.
- The generated charts are watermarked with `//Auto generated by osu2tja`.
